## Theory

A Content Provider is an Android component that manages and shares structured data between applications. It provides a standardized interface through which applications can access data exposed by other applications.

Android provides a built-in Contacts Content Provider that allows authorized applications to retrieve contact information stored on the device.

The `ContentResolver` class is used to communicate with a Content Provider. The `ContactsContract` class defines constants and content URIs for accessing contacts and related information.

To access contacts, the application must declare the `READ_CONTACTS` permission in `AndroidManifest.xml` and request the permission from the user at runtime.

Once permission is granted, the application can query the Contacts Content Provider and retrieve contact names and phone numbers.

## Scenario

A Contact Viewer application is developed to demonstrate data sharing using Android's Contacts Content Provider.

The application provides a vibrant, user-friendly interface with a Contact Viewer heading, a Load Contacts button, a status section, and a contact list.

When the user taps the Load Contacts button, the application checks whether contacts permission has been granted. If permission is available, it retrieves the contact names and phone numbers and displays them on the screen.

If permission is denied or no contacts are available, the application displays an appropriate status message.

The application only reads contact information and does not modify the device's contacts.

## Implementation Details

### 1. Contacts Permission

The application declares the following permission in `AndroidManifest.xml`:

```xml
<uses-permission android:name="android.permission.READ_CONTACTS" />
```

The application checks and requests this permission at runtime before accessing contacts.

### 2. Contacts Content Provider

The application uses:

`ContactsContract.CommonDataKinds.Phone.CONTENT_URI`

This URI provides access to phone contact records exposed by the Contacts Provider.

### 3. ContentResolver

The `ContentResolver.query()` method retrieves contact information using the required URI and projection.

The application retrieves the following fields:

- `DISPLAY_NAME`: Contact name.
- `NUMBER`: Contact phone number.

### 4. Cursor

The returned cursor is used to iterate through the retrieved records. The cursor is closed safely after reading the data.

### 5. User Interface

The application uses XML layouts and Kotlin to display the contact records.

The interface includes:

- A purple-indigo gradient header.
- A Load Contacts button.
- A status card.
- A contact list.
- Rounded backgrounds and a modern color scheme.
